# IMMAMANNA App

Aplikasi desktop (Windows portable x64, offline): Sekretaris & Bendahara.

## Cara membuat .exe
1. Buka tab **Actions** → **Build EXE Windows (portable x64)** → **Run workflow**.
2. Tunggu selesai (±3–5 menit), buka run yang hijau → bagian **Artifacts** → unduh **IMMAMANNA-portable**.
3. Ekstrak zip, jalankan `IMMAMANNA-portable.exe` (tanpa instal).

Data tersimpan di folder `IMMAMANNA-data` di samping file .exe — salin folder itu bersama .exe untuk memindahkan data.
